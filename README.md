# 🤖 Automação Inteligente de Atendimento de E-mails com IA

## 📌 Sobre o projeto
Automação desenvolvida para classificar e responder e-mails automaticamente utilizando Inteligência Artificial.

## ⚠️ Problema
Empresas recebem muitos e-mails e perdem tempo classificando e respondendo dúvidas repetitivas.

## 💡 Solução
Criei uma automação no Make que:
- Classifica e-mails
- Identifica dúvidas FAQ
- Gera respostas automáticas
- Encaminha casos complexos para humanos

## ⚙️ Como funciona
1. Leitura de e-mails (Outlook)
2. Classificação: dúvida ou não
3. Consulta na planilha para buscar perguntas e respostas relacionadas (base FAQ)
4. IA classifica como FAQ ou não
5. Se for FAQ:
   - Gera resposta com base na resposta encontrada na planilha
   - Cria rascunho
6. Se não for:
   - Envia para suporte humano
7. Organização em pastas

## 🛠️ Tecnologias
- Make (Integromat)
- Groq (IA)
- Excel
- Outlook

## 📊 Resultados
- Redução do tempo de resposta
- Automação de tarefas repetitivas
- Melhor organização de e-mails

## 🚀 Diferenciais
- Uso de IA na tomada de decisão
- Human-in-the-loop (validação)
- Estrutura escalável
